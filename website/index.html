Mining

Draw the sword.

Forging is permissionless. Bring the axiom, grind the 128-round maze until four zero bytes bow, and the protocol mints your steel. Verify any forge with the same command.

Take up the Axiom

Clone the repo. The thirteen words are public — no gatekeeper, no allowlist.

Grind the Maze

Run the Ω′ Δ18 miner. Difficulty 4: find a nonce whose digest opens with four zero bytes.
