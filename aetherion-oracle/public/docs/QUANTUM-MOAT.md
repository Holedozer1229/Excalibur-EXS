**1 · Receipt format (`caduceus.seal.v1`)**  
Every inference class can emit a third-party-verifiable cryptographic receipt: digest, program words, schema version. GPUs emit tokens. AQAI emits proofs. Once integrators bind agents and audit pipelines to this schema, switching cost is semantic — not cosmetic.

**2 · ISA binary continuity**  
Axiom 8: Soft Silicon opcodes match the die. Adopters compile `CAD.BRAID`, `CAD.SKIN`, `CAD.EP`, `CAD.SEAL` today; FPGA (G2) and MPW (G4) must execute the same binary map. This is the hardware moat CUDA cannot bolt on with a driver update.

**3 · Physics hierarchy**  
Hatano–Nelson skin memory piles working set to the edge — topology replaces associative cache tax. Exceptional-point logic switches modes via coalescence, not Boolean thresholds. Octonion ALU encodes non-associative causal braid order. These are **native machine modes**, not PyTorch extensions.

Provisional claims target seal-native compute pipeline, twin-pipe cognition schedule, NH/EP fabric integration. See `legal/patent/01-invention-disclosure.md` and `03-claims-outline.md`. Filing is roadmap — not a granted monopoly claim today.

**6 · Founder network / sovereign wedge**

**7 · Time**
