# Trademark guide — AETHERION™, AQAI™, Caduceus™

> **Disclaimer:** This document is operational guidance for the founder.
> It is **not legal advice**. Consult a trademark attorney before filing.

## What a trademark protects

A **trademark** protects **brand identifiers** — names, logos, slogans — that
distinguish your goods and services from others. It does **not** protect:

- Source code (copyright / BSD-3 license)
- Invention methods (patents)
- General ideas or concepts

## Marks to consider

| Mark | Suggested use | Notes |
|------|---------------|-------|
| **AETHERION™** | Product platform, oracle app, company name | Primary house mark |
| **AQAI™** | Chipset family, ISA, Verified Cognition Silicon category | Technical product mark |
| **Caduceus™** | Control plane, twin-pipe cognition, SDK/API brand | **Prior-art risk** — see below |

### Caduceus prior-art flag

"Caduceus" appears in medical, mythology, and existing tech branding contexts.
Before filing, run a **comprehensive USPTO TESS search** and common-law web
search. Your claim may be stronger when used as **Caduceus-powered** or in
combination with AETHERION/AQAI (e.g., "Caduceus ISA" in Class 9). A lawyer
can advise on likelihood of confusion vs. existing marks.

## USPTO filing basics

1. **Search first** — [USPTO Trademark Search (TESS)](https://tmsearch.uspto.gov/)
2. **Choose filing basis** — typically *Intent to Use* (1(b)) if not yet selling
   marked hardware, or *Use in Commerce* (1(a)) if already using the mark in trade
3. **File via** [Trademark Center](https://www.uspto.gov/trademarks/apply) (TEAS Plus
   or TEAS Standard)
4. **Monitor** — office actions, oppositions, maintenance deadlines

## Recommended Nice classes

USPTO uses **international classes** (not "business class 3" — that phrase
sometimes confuses people with **BSD-3-Clause**, which is unrelated).

| Class | Typical goods/services for AQAI |
|-------|----------------------------------|
| **Class 9** | Computer chips; downloadable software; AI inference SDK; semiconductor design files; scientific apparatus |
| **Class 42** | SaaS; cloud computing; software design; AI research services; technical consulting on chip architecture |
| **Class 35** (optional) | Business consulting; marketing services for tech products — only if you actively offer B2B advisory under the mark |

**Class 9 + 42** is the usual pair for a fabless chip + software stack.
Add **Class 35** only if you sell business/marketing services under the same brand.

## Marking convention (unregistered)

Until USPTO registers a mark, use:

```
AETHERION™ · AQAI™ · Caduceus™
```

Do **not** use ® unless you hold an active registration for that exact mark
in the relevant class.

## Estimated fees (2026 — verify on USPTO fee schedule)

| Item | Approx. |
|------|---------|
| TEAS Plus per class | ~$250 |
| TEAS Standard per class | ~$350 |
| Intent-to-Use extension / Statement of Use | additional fees later |

Micro/small-entity discounts apply to **patents**, not trademark per-class fees
(the same way).

## After filing

- Record application serial numbers in your CRM
- Set calendar reminders for office-action deadlines
- Align README, NOTICE, pitch deck, and product UI to consistent ™ usage
- Do not claim "registered trademark" until registration issues
