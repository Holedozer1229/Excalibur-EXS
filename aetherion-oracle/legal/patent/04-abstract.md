# Abstract (≤150 words)

## Draft abstract — AQAI provisional

A verified cognition processing system integrates seal-native compute, twin-pipe
Caduceus control, non-Hermitian skin memory, exceptional-point logic,
proof-of-memory retention, an octonion arithmetic lane, homomorphic seal
commitments, and soft-to-hard instruction continuity in a unified architecture.
A dual-pipeline execution unit braids generative Sphinx-pipe and memorial
Anubis-pipe signals each cycle in a Caduceus arithmetic logic unit. A seal
input/output controller computes cryptographic digests as an integral pipeline
stage responsive to seal-class instructions rather than as post-hoc software
attestation. Skin memory tiles apply asymmetric hop parameters to localize
working data to a boundary. An exceptional-point fabric enables topological mode
switching. A shared Caduceus opcode map is implemented identically in software
simulation and target hardware. Methods and computer-readable media embodiments
are disclosed. *(148 words)*
