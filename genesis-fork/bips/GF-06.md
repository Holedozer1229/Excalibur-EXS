# GF-06: Issuance — subsidy and halving

| Field | Value |
|-------|-------|
| BIP | GF-06 |
| Title | Issuance: subsidy and halving |
| Author | Travis Dale Jones |
| Status | Active |
| Created | 2026-09-21 |

## Abstract

50 GSF per block, halving every 210,000 blocks: a second 21,000,000 GSF
issuance on the fork chain. `subsidy(height) = 50·10⁸ >> (height //
210000)` satoshis-equivalent (the fork's base unit).

## Motivation

"Bitcoin's history, restarted": the same issuance schedule Satoshi
chose, replayed from the fork's block 1. No premine, no dev tax — the
fork's block 1 pays 50 GSF to an anyone-can-spend coinbase exactly as
specified here.

## Specification

1. Base unit: 1 GSF = 100,000,000 base units (8 decimals, Rosetta
   convention).
2. `subsidy(height) = 5,000,000,000 >> (height // 210000)` base units.
3. Halving interval: 210,000 blocks (≈4 years at 600 s spacing).
4. Total supply cap: 21,000,000 GSF.
5. Coinbase value MUST equal `subsidy(height) + fees` exactly; any other
   value invalidates the block.

## Rationale

Identical-to-Bitcoin issuance keeps the monetary argument simple and
auditable: one number changed (the chain), zero numbers changed (the
money).

## Reference implementation

`genesis_fork.py`: `subsidy()`; `validate_block()` (coinbase value
check); `excal.py`: `mine_one()` funds the coinbase with
`subsidy(height) + fees`.

## Test vectors

- `subsidy(1) == 5_000_000_000`; `subsidy(209999) == 5_000_000_000`;
  `subsidy(210000) == 2_500_000_000`
- Mainnet blocks 1–5 each pay exactly 50 GSF (`00f2052a01000000` LE in
  the coinbase output).
